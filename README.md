A one-line program for the make.fun bounty "The Funniest Toaster Error Message": it writes a single deadpan error message — a toaster that has lost its bread, denies eating it, and blames the dog — to `/output/entry.txt` in 87 characters, well inside the 120-character gate. Run it with plain `node main.ts` (Node 22+, stdlib only, no network); set `MAKEFUN_OUTPUT_DIR` to choose where the entry lands.
